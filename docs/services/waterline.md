# Waterline — LXC 107

Serveur de **test** pour le mod naval Waterline et son écosystème de jeu de rôle.
Ce n'est pas un serveur de production.

| | |
|---|---|
| LXC | 107 `waterline`, sur **galahad** |
| Tailscale | `waterline` (`100.93.179.106`) |
| Dépôt | `GabinSMD/waterline`, privé |

:::warning[Le développement ne se fait pas sur penny]
penny ne peut ni compiler le mod ni lancer un client Minecraft. Le cycle est :
développement sur le PC personnel, puis déploiement ici pour tester en conditions
serveur. Ne pas chercher de chaîne de build sur le homelab, il n'y en a pas.
:::

Pour le serveur de jeu en service, voir [Project Zomboid](zomboid.md), qui a ses
propres contraintes de mods et de comptes.
